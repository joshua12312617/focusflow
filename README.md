# FocusFlow

A polished, distraction-light Pomodoro timer and task list built with plain HTML, CSS, and JavaScript.

## Features

- Work, short-break, and long-break sessions with configurable durations
- Start, pause, reset, and skip controls; visual progress ring and browser title countdown
- Task list with completion states and session counts
- Settings and tasks persist locally in the browser
- Keyboard-friendly controls and responsive layout
- No frameworks, dependencies, build tools, or server required

## Run

Open `index.html` directly in a modern browser, or run a local static server:

```sh
python -m http.server 8000
```

Then visit <http://localhost:8000>. Data is stored in localStorage for that browser.
